# Muhammad Naseeb, AI Engineer

Welcome to the repository for my personal portfolio. This project is a minimal, single-page portfolio website designed to showcase my experience, projects, and skills as an AI Engineer. 

## 🌟 Key Features

- **Minimalist Single-Page Design**: A clean and modern interface focusing on core professional information.
- **Interactive AI Agent (`/chat`)**: The standout feature of this portfolio is an integrated chat interface powered by a Retrieval-Augmented Generation (RAG) backend application. 
  - **Persona**: The AI acts as a digital representation of myself.
  - **Capabilities**: Users can interact with the agent to ask context-aware questions about my professional experience, projects, skills, and contact information (e.g., Gmail).

## 🛠️ Tech Stack (Planned)

- **Frontend**: React (Vite) for a fast, responsive user interface.
- **Backend**: AI Agent and RAG system (Implementation details TBD).
- **Knowledge Base**: Vector store containing my resume, project details, and professional background.

## 🚀 Getting Started

### Frontend Development

The frontend is built with Vite and React.

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
